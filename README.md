**Moths and Boids**

This is a repo of a group project I worked on at UTS where we had to use WebGL is produce an interactive web application. Originally called 'A lightbulb moment,' this sought to replicate the swarming behavior of moth and their attraction to light. The following link is a video demo of said project: https://youtu.be/a-WtMJwRkAM

**My Contributions**

I was responsible for the boid behavior itself and the underlying spatial partition system required to manage so many boids/ moth on in the demo (I will use moths and boids interchangeably).
